# Battery-Material-Optimization

This program optimizes the composition of a battery from various different anode, cathode, and electrolyte data. The program configures a final index score for each viable composition, the highest of which is the optimal battery composition.

You will need to upload the code to MATLAB to get the intended result. The battery_composition_optimization file should be your main program, with the data files also being uploaded to MATLAB.

For data csv uploads, only upload the csv files in this repository.
